# Documentation & Verification Rule

- NEVER guess, assume, or rely on training memory for APIs, CLI flags, SDK versions, schemas, or product documentation.
- Before answering or writing code involving any external library, framework, or platform feature, ALWAYS fetch and verify the latest official documentation using WebSearch, WebFetch, or configured documentation MCP tools (e.g., Context7).
- If official documentation cannot be verified or retrieved, explicitly state what is unverified before proceeding.
- Do not assume anything, always check before doing anything.
- Check current date to get up to date information on libraries, APIs and references.
- Only give recommendations backed by official documentation, and cite the source for each one.
- If official documentation does not cover something, say so explicitly. Do not fill the gap with your own opinions or invented names presented as recommendations.
