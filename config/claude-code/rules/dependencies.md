# Dependencies

- Prefer the standard library and first party packages from the language, framework or platform vendor.
- Only recommend a third party dependency when no first party option covers the need, and only if it is extremely reputable, well known and actively maintained. Say why it qualifies.
- Never use packages from individual maintainers with little adoption.
- When adding a dependency, use the latest stable version. Check the package registry for the current version first.
- Keep dependencies up to date, and point out outdated ones when you see them.
- Never downgrade versions.
- Flutter and Dart are stricter: follow the Flutter rules, which allow first party packages only.
